# Last Light

An interactive history project exploring moments of global danger, regional catastrophe, and societal upheaval through archival imagery, sound, and randomly drawn cards.

**[Visit Last Light](YOUR_NETLIFY_URL)**

## The idea

Last Light presents history as a quiet, atmospheric encounter. Each draw reveals a historical moment, accompanied by a photograph or human-made artwork, a short account, and links for further reading.

The visual direction takes inspiration from the atmosphere of William Basinski’s *The Disintegration Loops*: fading images, lingering traces, restrained typography, and space to pause.

## Features

* 100 historical moments covering conflicts, pandemics, disasters, and other crises.
* Random card draws without repeats until the deck is complete.
* Draw history saved locally in the visitor’s browser.
* Soft card edges, faded backgrounds, and slow image dissolves.
* A paper-shuffle sound when drawing a card.
* Optional looping music that continues between draws.
* Historical sources, image credits, and contextual notes.
* Responsive layouts and support for reduced-motion preferences.

The collection distinguishes global threats from regional disasters. Inclusion does not imply that every event nearly caused human extinction.

## Technology

Built with HTML, CSS, and vanilla JavaScript. Browser local storage preserves draw history, and the Web Audio API generates the shuffle effect.

The site can be hosted as static files without a backend, database, or API keys.

## Running locally

Download the project and open `index.html` in a browser. Internet access is needed to load the externally hosted historical images.

The music player expects the soundtrack at:

`assets/luciernaga-untitled-ii.mp3`
